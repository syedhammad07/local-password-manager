# Asana: A Practical One-Page Reference Guide for Agile Teams

*Group G2 · Local Password Manager v1.0 launch*

[← Back to the report](../REPORT.md)

**What Asana is:** a cloud-based work management tool for planning, organising and tracking team work. Work is organised as tasks inside projects, and the same project can be viewed as a List, Board, Timeline, Calendar or Dashboard.

**Purpose:** to give everyone one shared, transparent place to see who does what, by when, and why, from a single task up to company goals.

**Value for agile project management:**
- **Visibility:** boards and lists make the flow of work and its blockers visible to everyone.
- **Adaptability:** priorities, owners and dates change in seconds, and dependencies show the impact.
- **Less admin:** forms, rules and templates automate repetitive coordination.
- **Alignment:** Goals and Portfolios connect sprint-level work to strategy.

**Key features:**

| Feature | What it does | Our example |
|---|---|---|
| Board / List | Kanban columns or a structured table | Launch Requests stages |
| Custom fields | Structured data per task | Request Type, Priority |
| Forms | Standardised intake | Launch Request Form |
| Rules | Trigger → condition → action | R1 auto-assign, R2 move to Done |
| Templates | Reusable tasks with subtasks | Marketing Asset Request |
| Dependencies and approvals | Order and sign-off | Go / No-Go decision |
| Timeline and milestones | Roadmap and key dates | v1.0 launch day, 15 Jan 2027 |
| Goals, Portfolios, Dashboards | Strategy and reporting | Company goal, Launch 2027 portfolio |

**Best use cases:**
- Product launches and marketing campaigns.
- Request intake and approvals.
- Cross-functional coordination.
- Lightweight Scrum or Kanban for mixed teams.
- Portfolio reporting to management.

**Strengths:**
- Easy to learn for non-technical teams.
- Many views of the same data.
- Strong no-code automation.
- Good cross-project visibility.

**Limitations:**
- No native story points or burndown charts.
- Weak budgeting and resource planning.
- No critical path.
- No risk register.
- Advanced features (Goals, Portfolios, advanced rules) need paid plans.
- It's a cloud tool, so it's not for storing secrets.

**When another tool may be better:**
- **Jira:** software development with sprints, bugs and code integration.
- **MS Project or Primavera:** waterfall projects, critical path, cost and resource planning.
- **Trello:** very small, simple boards.
- **Miro:** retrospectives and workshops.
